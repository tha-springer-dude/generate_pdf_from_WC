# Tamino PDF Generator for WooCommerce

A custom WordPress plugin that generates downloadable PDF travel documents from WooCommerce products.

## Features

- Generates PDF documents from WooCommerce product data.
- Includes product titles, descriptions, featured images and image galleries.
- Adds structured travel locations and tour station information.
- Supports multilingual content through Polylang.
- Attaches generated PDFs to WooCommerce products as downloadable files.
- Provides a PDF generation button within the product editing interface using Advanced Custom Fields (ACF).

## Technical Details

- **Platform:** WordPress
- **E-commerce:** WooCommerce
- **Language:** PHP
- **PDF Library:** TCPDF
- **JavaScript:** jQuery
- **Custom Fields:** Advanced Custom Fields (ACF)
- **Multilingual Support:** Polylang

## How It Works

The plugin retrieves product information and associated travel data from WordPress and WooCommerce. It uses TCPDF to assemble the information into a formatted PDF document, including images, descriptions, locations and tour stations.

The generated PDF is saved in the WordPress uploads directory and registered as a downloadable file associated with the WooCommerce product.

## Project Context

Developed for Tamino Travel to automatically create detailed travel documents for digital tour products.
